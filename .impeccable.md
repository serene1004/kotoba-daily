## Design Context

### Users

Korean speakers building a daily Japanese vocabulary habit. The first task is to quickly find a word, save it, and review it in short sessions.

### Brand Personality

Light, encouraging, and quietly playful. The interface should feel like a daily quest, never an exam.

### Aesthetic Direction

Warm paper background, ink-black text, and muted vermilion accents. Keep the game feel subtle: progress, completion, and streaks should motivate without pressure.

### Design Principles

- Put the single daily quest first.
- Make progress and completion immediately legible.
- Use semantic controls, visible focus states, and sufficient contrast.
- Prefer local-first interactions; APIs enrich the experience but do not block the core study flow.
